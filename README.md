# Mortgage Calculator - Lloyds Bank Job Simulation

## 📌 Project Overview
This project is a digital wireframe of a mortgage calculator developed as part of the **Lloyds Bank Job Simulation **. The goal was to take initial customer insights and design a tool that makes the mortgage process clearer, more intuitive, and accessible for all users.

## 🎨 Design Philosophy
Following the project brief, I focused on three core principles:
* **Simplicity:** A minimalist layout designed to prevent "information overload" and guide the user through the calculation process.
* **Clarity:** A strong visual hierarchy where the most important information—the monthly payment—is the most prominent element.
* **Accessibility:** Use of semantic HTML and high-contrast labels to ensure usability for customers using assistive technologies.

## 🛠️ Features
* **Real-time Calculation:** Interactive inputs for Property Price, Down Payment, Interest Rate, and Loan Term that update results instantly.
* **Responsive UI:** Built using React and custom CSS to ensure a clean layout that works well on various devices.
* **User-Centric Inputs:** Clearly defined forms and labels to enhance navigation and straightforward use.

## 🚀 The Development Process
1. **Sketching:** Began with paper sketches to map out a logical flow for the user.
2. **Wireframing:** Translated those sketches into a digital version using **Visual Studio Code** and **React**.
3. **Styling:** Applied custom **CSS** to enhance visual appeal while maintaining consistency and a cohesive user experience.
4. **Refinement:** Developed the tool to address key issues identified in customer feedback.

## 💻 Installation and Setup
To run this project locally:
1. Clone the repository.
2. Navigate to the folder in your terminal.
3. Run `npm install` to set up the environment.
4. Run `npm start` to view the design in your browser.
